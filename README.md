# Villa des Vergnes – Soustons (Landes)

Site vitrine de location de la maison (7 pages, 5 langues).

## Modifier le site
- **Prix, saisons, dates réservées, services, coordonnées** : `config.js`
- **Textes** (une langue par fichier) : `textes/`
- **Photos** : `photos/` (préparées avec `outils/optimiser_photos.py`)
- **Demandes de réservation par Google Sheets** : voir `outils/GUIDE-GOOGLE-SHEETS.md`

## Voir le site sur son Mac
Double-cliquer sur « Voir le site.command », ou lancer `python3 outils/serveur_local.py` puis ouvrir http://localhost:8090

## Mise en ligne
Publié avec GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).
